## 0. 结论

### 存在等待，但主要不是进程间互相等待

同步点等待合计 2622.0 rank·ms，占 墙钟×进程数 的 50.58%；平均 4.05 个 rank 同时在等待（占 50.6%）。 到齐前等待只占全部等待的 33%（低于阈值 50%），主要是集合通信原语自身的开销。

| 关键量 | 值 |
|---|---|
| **相互等待时长（到齐前等待合计）** | **856.40 rank·ms**（0.8564 核·秒） |
| 同步点等待合计（相互等待 + 原语开销） | 2622.02 rank·ms（2.6220 核·秒） |
| 其中：到齐前等待（相互等待） | 856.40 rank·ms（占 33%） |
| 其中：到齐后通信耗时（原语开销） | 1765.62 rank·ms（占 67%） |
| 平均同时在等待的 rank 数 | 4.047 / 8（50.58%） |
| 等待占 墙钟×进程数 的比例 | 50.585% |
| 最大到达离散度 | 31.21 ms |
| 最集中的最后到达者 | rank 7（占同步点的 37.95%） |

> 判定阈值（可在命令行调整）：平均同时在等待的 rank 占比 < 5% 视为无实际影响；到齐前等待占全部等待 ≥ 50% 且最后到达者分散在多个进程之间，判定为相互等待。
