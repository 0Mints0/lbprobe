## 0. 结论

### 存在相互等待

同步点等待合计 11160.0 rank·ms，占 墙钟×进程数 的 68.55%；平均 5.48 个 rank 同时在等待（占 68.5%）。其中 78% 属于到齐前等待（我算完了在等其它进程），合计 **8709.8 rank·ms**（≈ 8.710 核·秒）。 等待分散在多个进程之间（最集中的 rank 5 也只占 15%），属于进程之间进度不一致造成的相互等待。

| 关键量 | 值 |
|---|---|
| **相互等待时长（到齐前等待合计）** | **8709.76 rank·ms**（8.7098 核·秒） |
| 同步点等待合计（相互等待 + 原语开销） | 11159.96 rank·ms（11.1600 核·秒） |
| 其中：到齐前等待（相互等待） | 8709.76 rank·ms（占 78%） |
| 其中：到齐后通信耗时（原语开销） | 2450.19 rank·ms（占 22%） |
| 平均同时在等待的 rank 数 | 5.484 / 8（68.55%） |
| 等待占 墙钟×进程数 的比例 | 68.549% |
| 最大到达离散度 | 157.99 ms |
| 最集中的最后到达者 | rank 5（占同步点的 15.33%） |

> 判定阈值（可在命令行调整）：平均同时在等待的 rank 占比 < 5% 视为无实际影响；到齐前等待占全部等待 ≥ 50% 且最后到达者分散在多个进程之间，判定为相互等待。
