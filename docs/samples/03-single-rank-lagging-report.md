## 0. 结论

### 存在进程间等待，形态是单向等待（归因于单个进程）

同步点等待合计 145344.3 rank·ms，占 墙钟×进程数 的 85.29%；平均 6.82 个 rank 同时在等待（占 85.3%）。其中 97% 属于到齐前等待（我算完了在等其它进程），合计 **141600.4 rank·ms**（≈ 141.600 核·秒）。 **这份相互等待的 99% 都归因于 rank 7**（它在 41% 的同步点上最后到达），即其余进程在等它一个：这是单点进度落后（负载不均或设备/IO 阻塞），不是双向的互相等待。

> 判定阈值（可在命令行调整）：平均同时在等待的 rank 占比 < 5% 视为无实际影响；到齐前等待占全部等待 ≥ 50% 且最后到达者分散在多个进程之间，判定为相互等待。
